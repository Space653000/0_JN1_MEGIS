# UI-0 execution archive

此目錄保留 UI-0 的最終狀態、schema 與驗證快照，僅作歷史證據。

UI-0 已於 2026-09-16 完成使用者驗收。自 G0 起，正式即時施工狀態改由以下檔案管理：

- `execution/PROJECT_STATE.md`
- `execution/WORK_QUEUE.yaml`
- `execution/BLOCKERS.yaml`
- `execution/LAST_VERIFICATION.json`

進度網站也已改讀正式 `WORK_QUEUE.yaml`；不得再以本目錄的封存 JSON 驅動後續 Gate。
