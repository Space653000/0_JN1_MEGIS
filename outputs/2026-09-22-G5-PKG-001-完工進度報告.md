## 比較表

- `PKG-001 vs PKG-002`：PKG-001 管 manifest 可重建與 hash 可驗證；PKG-002 管檔案存在、可讀與 hash 一致性（如檔案缺失／內容變更即失敗）。
- `L1 byte hash vs L2 semantic fingerprint`：byte SHA-256 是檔案位元組層級指紋；語義層級以 `normalized_text_sha256` 等 kind 提供格式正規化後指紋，藍圖保留到後續 work item 深化。
- `positive vs negative cases`：positive 驗證合法 manifest 可重建與核對；negative 驗證未知 kind、錯誤 hash、重複 file 等必須被拒絕且帶正確錯誤碼。
