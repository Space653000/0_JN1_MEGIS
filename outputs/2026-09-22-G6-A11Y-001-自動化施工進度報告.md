## 人工證據契約補強

新增 Draft 2020-12 schema、版本化空白範本與 fail-closed verifier，把六項鍵盤與六項螢幕閱讀器檢查固定為 12 個 canonical IDs。完成紀錄必須包含具名 reviewer、個人執行 attestation、帶時區時間，以及 OS、瀏覽器與 assistive technology 版本；缺漏、重複、額外欄位、pending 混入 completed 狀態或 failed 無 notes 都會拒絕。

空白範本驗證成功但 `closureEligible: false`；帶 `--require-complete` 驗證同一範本會以 exit code 1 fail closed。這證明工具不會把「格式有效但尚未執行」誤判為驗收完成，也不會由 Agent 代填真人結果。

## 誠實邊界

- 自動化測試不是螢幕閱讀器人工抽查。
- jsdom 沒有實際 layout，因此不把 axe 的 DOM 結果當成完整視覺證明。
- 本段不把 Agent 操作或模擬輸入冒充真人 E3／E4 證據。
- 工作項仍為 `in_progress`，done／planned 計數不變。
