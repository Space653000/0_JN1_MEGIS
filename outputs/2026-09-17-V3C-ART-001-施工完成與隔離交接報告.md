## 4. Git attributes 與儲存邊界

- 一般文字：`* text=auto eol=lf`。
- Binary：STEP/STP/STL/FCStd/GLB/glTF/PDF。
- Byte-stable artifact text containers：`artifacts/**/*.dxf`、`artifacts/**/*.svg` 亦視為 binary，避免 checkout 改變 L1。
- `.runs/`、新的 artifact STEP/STL/DXF/FCStd/SVG/GLB/glTF/PDF 全部 ignore。
- Git 只保存小型可稽核證據與 golden；Design Run、CI artifacts、cache、build outputs 不進 Git。
- 沒有刪除歷史檔案、沒有改寫 history、沒有啟用 Git LFS，也沒有使用外部 object storage。
