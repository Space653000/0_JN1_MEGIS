# MEGIS UI-0

Local-only React + TypeScript + Vite prototype for the MEGIS construction
progress center and guided design experience.

## Run locally

```powershell
npm run dev
```

The development server is fixed to `http://127.0.0.1:4173`. Do not expose it on
`0.0.0.0` or add external runtime assets, analytics, telemetry, or APIs.

## Verify

```powershell
npm run lint
npm run typecheck
npm run test
npm run build
```

UI-0 is an interaction prototype. It does not generate engineering artifacts.
